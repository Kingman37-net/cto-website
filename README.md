## 🎨 Design System

The website follows a modern technology-focused visual language inspired by the KDCN design system.

**Primary visual characteristics**

- Dark navy / black foundation
- Cyan and blue accents
- Glass-style cards
- Gradient CTAs
- Responsive layouts
- Subtle animations
- Light / dark theme support
- Mobile navigation
- Accessibility-conscious structure

---

## 💻 Technology

**The website is intentionally lightweight.**

Built with:

- HTML5
- CSS3
- Vanilla JavaScript
- SVG / web imagery
- Responsive design
- No frontend framework required

No React, Vue, Angular, Bootstrap, or other large frontend framework is required.

---

## 📱 Responsive Design

The website is designed for:

- Mobile phones
- Tablets
- Laptops
- Desktop computers

**The layout automatically adapts to different screen sizes.**

---

## ⚡ Performance Philosophy

The project follows a simple principle:

> Fast. Structured. Secure. Maintainable.

The website avoids unnecessary dependencies and keeps the frontend lightweight.

---

## 🔐 Security & Maintenance

The project is designed with basic web-security principles in mind.

Recommended practices include:

- HTTPS hosting
- Secure external resources
- Regular dependency review
- Regular backups
- Git version control
- Avoiding unnecessary third-party scripts
- Protecting contact-form endpoints
- Keeping public information intentional

---

## 🖼️ Images

During development, website imagery may reference externally hosted image assets.

For production deployment, local optimized image assets are recommended where practical.

**Recommended formats:**
- WebP
- PNG for transparent logos
- JPEG where photographic compatibility is required
